# ESP32-C3 Boards

Einzelner RISC-V-Kern, die kleinste und günstigste Stufe. Spitzenhashrate **~402 KH/s**.

| Board                       | Hashrate       | Chip      |
| --------------------------- | -------------- | --------- |
| Seeed XIAO ESP32-C3         | **396.9 KH/s** | ESP32-C3  |
| ESP32-C3 0.42" OLED         | **315.1 KH/s** | ESP32-C3  |
