# ESP32-C5 Boards

Der ESP32-C5 ist ein neuerer Dual-Band-RISC-V-Chip. NMMiner bietet Unterstützung, einschließlich des dedizierten NM-CYD-C5-Entwicklungsboards.

| Board                  | Hashrate       | Chip      |
| ---------------------- | -------------- | --------- |
| ESP32-C5 DevKitC-1     | **150.2 KH/s** | ESP32-C5  |
| NM-CYD-C5              | **150.2 KH/s** | ESP32-C5  |

:::info
Die C5-Unterstützung erhält weiterhin Hashrate-Verbesserungen. Aktuelle Zahlen finden Sie im [GitHub-Release-Log](https://github.com/NMminer1024/NMMiner#release-log).
:::
