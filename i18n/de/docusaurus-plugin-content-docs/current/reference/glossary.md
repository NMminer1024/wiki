# Glossar

| Begriff                    | Definition                                                                       |
| ----------------------- | -------------------------------------------------------------------------------- |
| **AP-Modus**             | Soft-AP-Captive-Portal, auf das NMMiner zurückfällt, wenn es das WiFi nicht erreichen kann. |
| **CYD**                 | „Cheap Yellow Display" — eine Familie kostengünstiger ESP32+TFT-Boards.          |
| **DGB / DigiByte**      | Eine SHA-256d-Altcoin. NMMiner unterstützt DGB ab Werk — gleiche Firmware, anderer Pool. |
| **Hashrate**            | Hashes pro Sekunde. Auf NMMiner in KH/s angegeben.                               |
| **Job**                 | Eine Arbeitseinheit, die vom Pool geliefert wird (`mining.notify`).               |
| **Ladder**              | Die Opt-in-globale Top-10-Schwierigkeits-Bestenliste, veröffentlicht unter [ladder.nmminer.com](https://ladder.nmminer.com/) und auf dem Gerätebildschirm gespiegelt. Siehe [Ladder](../user-guide/ladder.md). |
| **Licence**             | Per-Gerät-Aktivierungszeichenfolge, die ein Board an ein Firmware-Image bindet.  |
| **NM Monitor**          | Die browserbasierte UI, die von jedem Miner auf Port 80 bereitgestellt wird.     |
| **Nonce**               | Das 32-Bit-Feld, über das ein Miner bei der Suche nach einer Share iteriert.     |
| **Pool-Diff**           | Minimale Share-Schwierigkeit, die der Pool akzeptiert.                           |
| **Probe**               | Der leichtgewichtige `/probe`-Endpunkt für die LAN-Identifikation.               |
| **Share**               | Ein Hash, der die Pool-Diff erfüllt, aber nicht die Netzwerk-Diff.               |
| **SoloBTC**             | NMMiners offizieller Mining-Pool: [solobtc.nmminer.com](https://solobtc.nmminer.com). Der Standard-Pool auf jedem ausgelieferten Gerät. |
| **Stratum**             | Das Pool-Protokoll, das NMMiner spricht. Nur v1.                                |
| **Swarm**               | Das Swarm-Menü in NM Monitor — LAN-weite Miner-Aggregation, ohne Installation. Bis zu 255 Geräte pro /24-Subnetz. |
