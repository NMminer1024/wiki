# LED-Anzeige

Boards mit einer On-Board-RGB- oder Status-LED nutzen sie als Echtzeit-Miner-Herzschlag.

| Zustand           | LED-Muster                          |
| --------------- | ------------------------------------ |
| WiFi-Verbindung | Atmen                            |
| Mining          | Langsamer Puls, synchronisiert zur Share-Einreichung |
| Share akzeptiert  | Schnelles helles Aufblitzen                   |
| Share abgelehnt  | Schnelles gedimmtes / aus-Aufblitzen                |
| Fehler           | Feste Farbe (modellabhängig)       |

Die LED kann im Konfigurationsportal **deaktiviert** werden, wenn Sie das Licht stört.
