# Discovery Endpoints

이 엔드포인트는 **모든 클라이언트** — NM Monitor, 사용자 정의 대시보드, 다른 마이너 — 가 LAN에서 NMMiner 기기를 검색할 수 있도록 존재합니다.

---

## `GET /probe`

경량 신원 프로브입니다. 호스트가 NMMiner인지 확인하는 데 사용합니다.

### 응답

```json
{
  "model":    "NMMiner",
  "hostname": "nm-cyd-c5-ab12cd",
  "ver":      "v2.0.04",
  "sw":       320,
  "sh":       240,
  "hr":       956432,
  "sbd":      0.0421,
  "ebd":      1.7833,
  "ut":       4321
}
```

| 필드      | 유형     | 의미                                                       |
| ---------- | -------- | ------------------------------------------------------------- |
| `model`    | string   | 항상 `"NMMiner"`. 모니터링 트래픽을 라우팅하는 데 사용합니다.     |
| `hostname` | string   | 설정 가능한 호스트명.                                        |
| `ver`      | string   | 펌웨어 버전.                                             |
| `sw`       | integer  | 화면 너비(픽셀).                                       |
| `sh`       | integer  | 화면 높이(픽셀).                                      |
| `hr`       | number   | 현재 해시레이트(H/s).                                      |
| `sbd`      | number   | 이번 세션의 최고 셰어 난이도.                           |
| `ebd`      | number   | 역대 최고 셰어 난이도.                                   |
| `ut`       | integer  | 부팅 이후 가동 시간(초).                 |

### 예시

```bash
curl http://192.168.1.42/probe
```

---

## `GET /alive`

LAN 검색 목록. 기기 자신의 IP와 로컬 서브넷에서 발견한 다른 모든 NMMiner를 반환합니다.

### 쿼리 파라미터

| 이름      | 선택 | 효과                                                          |
| --------- | -------- | --------------------------------------------------------------- |
| `rescan`  | 예      | 존재하면 즉시 재스캔을 요청합니다(10초 디바운스).     |
| `src`     | 예      | 호출자가 다른 마이너일 때 `src=swarm`을 전달합니다 — 기기 자체 검색 스레드를 잠자게 유지합니다. |

### 응답

```json
{
  "self":         "192.168.1.42",
  "ips":          ["192.168.1.42", "192.168.1.43", "192.168.1.44"],
  "scanning":     true,
  "progress":     128,
  "total":        254,
  "next_scan_in": 0
}
```

| 필드          | 유형             | 의미                                                  |
| -------------- | ---------------- | -------------------------------------------------------- |
| `self`         | string           | 기기 자신의 IP(`ips`의 첫 번째 항목이기도 함).      |
| `ips`          | string[]         | 현재 LAN에서 알려진 모든 NMMiner IP(자신 포함). |
| `scanning`     | boolean          | 스윕 진행 중이면 `true`.                     |
| `progress`     | integer (0-254)  | 현재 프로브 중인 마지막 옥텟(유휴 시 0).                   |
| `total`        | integer          | 항상 `254` — /24 서브넷 하나의 크기.               |
| `next_scan_in` | integer          | 다음 예약 스윕 시작까지의 초(`진행 중이면 0`). |

### 예시 — LAN의 모든 마이너 나열

```bash
curl http://192.168.1.42/alive | jq '.ips'
```

### 참고

- 검색 스레드는 기기가 Miner 페이지에 있거나 NM Monitor의 Swarm 메뉴가 열려 있는 동안에만 실행됩니다. `/alive`를 호출하면 깨어납니다.
- 응답은 점진적으로 구성됩니다 — `scanning`을 `true` → `false`로 추적하려면 반복 호출하세요.
