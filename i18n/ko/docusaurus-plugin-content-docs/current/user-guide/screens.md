# Screen Pages

디스플레이가 있는 보드는 작은 페이지 세트를 순환합니다. [Buttons & Touch](./buttons.md)에 정의된 제스처로 전환합니다 — 하드웨어에 따라 탭, 더블 클릭 또는 스와이프.

NMMiner는 다음 기본 크기에 대한 레이아웃을 제공합니다:

```
128x64    128x128    160x80     240x135
240x240   320x170    320x172    320x240
480x320   536x240
```

## 페이지

| 순서 | 페이지       | 목적                                                                |
| ----- | ---------- | ---------------------------------------------------------------------- |
| 1     | **Loading**| 스플래시 + 부팅 상태, 펌웨어 버전, 네트워크 핸드셰이크.             |
| 2     | **Config** | AP 모드일 때 표시 — 캡티브 포털에 도달하기 위한 QR / IP / SSID.    |
| 3     | **Miner**  | 라이브 해시레이트, **세션 최고** 및 **역대 최고** 난이도, 승인 / 거부 셰어, 풀 URL, 가동 시간. 주요 "작업" 페이지. |
| 4     | **Clock**  | 큰 시계 + 날짜. 상승 시 녹색, 하락 시 빨간색으로 바뀌는 BTC 가격 티커 포함. 12 / 24시간 형식 선택 가능, 날짜 형식 구성 가능. |
| 5     | **Price**  | 두 가지 모드:<br/>• **K-line** — 메인 코인의 캔들 차트, 구성 가능한 간격(`15m`, `1h`, `4h`, `1d`, …).<br/>• **Wall** — 다중 코인 관심 목록 보기(최대 20쌍). |
| 6     | **Weather**| 현재 상태 + AQI + 3일 예보 + 일출 / 일몰. 온도(°C / °F), 풍속(km/h / mph / m/s), 고도계(기압 / 습도) 단위 선택 가능. |
| 7     | **Ladder** | **옵트인** 글로벌 Top-10 리더보드. 역대 최고 셰어 난이도로 순위. 지갑은 개인정보 보호를 위해 `앞4…뒤4`로 표시. 기본 꺼짐. 같은 데이터는 [ladder.nmminer.com](https://ladder.nmminer.com/) 웹에도 게시됩니다 — [Ladder](./ladder.md) 참조. |

:::info
페이지 순서는 모든 보드에서 동일합니다. 작은 / OLED 화면은 맞지 않는 페이지를 건너뜁니다. NMMiner는 마지막에 있던 페이지를 기억하고 전원 사이클 후 거기서 재개합니다(v1.8.20 이후).
:::

## 화면 보호기

마이너를 충분히 오래 유휴 상태로 두면 화면 보호기에 들어갑니다:

- **이미지 모드** — NM Monitor를 통해 업로드한 사용자 정의 이미지의 슬라이드쇼.
- **블랙 모드** — 백라이트를 끄거나(또는 OLED 대비를 최소로) 가장 낮은 전력 소비와 **절대적인 피크 해시레이트**를 실현합니다.

깨우기 제스처: `BOOT`(또는 `USER`) 단일 클릭, 또는 터치 스크린 탭. 자세히: [화면 보호기](./screen-saver.md).
