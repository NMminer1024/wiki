# Discovery エンドポイント

これらのエンドポイントは、**任意のクライアント**（NM Monitor、カスタムダッシュボード、他のマイナー）が LAN 上の NMMiner デバイスを検出できるようにするために存在します。

---

## `GET /probe`

軽量な識別プローブです。ホストが NMMiner であることを確認するために使用します。

### レスポンス

```json
{
  "model":    "NMMiner",
  "hostname": "nm-cyd-c5-ab12cd",
  "ver":      "v2.0.04",
  "sw":       320,
  "sh":       240,
  "hr":       956432,
  "sbd":      0.0421,
  "ebd":      1.7833,
  "ut":       4321
}
```

| フィールド      | 型     | 意味                                                       |
| ---------- | -------- | ------------------------------------------------------------- |
| `model`    | string   | 常に `"NMMiner"`。監視トラフィックのルーティングに使用します。     |
| `hostname` | string   | 設定可能なホスト名。                                        |
| `ver`      | string   | ファームウェアバージョン。                                             |
| `sw`       | integer  | 画面幅（ピクセル）。                                       |
| `sh`       | integer  | 画面高さ（ピクセル）。                                      |
| `hr`       | number   | 現在のハッシュレート（H/s）。                                      |
| `sbd`      | number   | このセッションの最高シェア難易度。                           |
| `ebd`      | number   | 過去最高のシェア難易度。                                   |
| `ut`       | integer  | 起動からの稼働時間（秒）。                 |

### 例

```bash
curl http://192.168.1.42/probe
```

---

## `GET /alive`

LAN 検出リスト。デバイス自身の IP に加えて、ローカルサブネットで検出した他のすべての NMMiner を返します。

### クエリパラメータ

| 名前      | 任意 | 効果                                                          |
| --------- | -------- | --------------------------------------------------------------- |
| `rescan`  | はい      | 指定された場合、即時再スキャンを要求します（10 秒デバウンス）。     |
| `src`     | はい      | 呼び出し元が別のマイナーの場合に `src=swarm` を渡します — デバイス自身の検出スレッドをスリープ状態に保ちます。 |

### レスポンス

```json
{
  "self":         "192.168.1.42",
  "ips":          ["192.168.1.42", "192.168.1.43", "192.168.1.44"],
  "scanning":     true,
  "progress":     128,
  "total":        254,
  "next_scan_in": 0
}
```

| フィールド          | 型             | 意味                                                  |
| -------------- | ---------------- | -------------------------------------------------------- |
| `self`         | string           | デバイス自身の IP（`ips` の最初のエントリでもあります）。      |
| `ips`          | string[]         | 現在 LAN で認識されているすべての NMMiner IP（自分自身を含む）。 |
| `scanning`     | boolean          | スイープ実行中は `true`。                     |
| `progress`     | integer (0-254)  | 現在プローブ中の最後のオクテット（アイドル時は 0）。                   |
| `total`        | integer          | 常に `254` — 1 つの /24 サブネットのサイズ。               |
| `next_scan_in` | integer          | 次回のスケジュールされたスイープ開始までの秒数（実行中は `0`）。 |

### 例 — LAN 上のすべてのマイナーを一覧表示

```bash
curl http://192.168.1.42/alive | jq '.ips'
```

### メモ

- 検出スレッドは、デバイスが Miner ページにある間、または NM Monitor の Swarm メニューが開いている間のみ実行されます。`/alive` を呼び出すと起動します。
- レスポンスは段階的に構築されます — `scanning` を `true` → `false` と追跡するには繰り返し呼び出してください。
