# 画面ページ

ディスプレイ付きのボードは、少数のページセットを循環表示します。ハードウェアに応じて、[ボタンとタッチ](./buttons.md) で定義されたジェスチャー（タップ、ダブルクリック、スワイプ）で切り替えます。

NMMiner は以下のネイティブサイズ向けのレイアウトを出荷します：

```
128x64    128x128    160x80     240x135
240x240   320x170    320x172    320x240
480x320   536x240
```

## ページ

| 順序 | ページ       | 目的                                                                |
| ----- | ---------- | ---------------------------------------------------------------------- |
| 1     | **Loading**| スプラッシュ + 起動状態、ファームウェアバージョン、ネットワークハンドシェイク。             |
| 2     | **Config** | AP モード時に表示 — キャプティブポータルへ到達する QR / IP / SSID。    |
| 3     | **Miner**  | ライブハッシュレート、**セッション最高** と **全期間最高** の難易度、承認 / 拒否シェア、プール URL、稼働時間。主要な「作業」ページ。 |
| 4     | **Clock**  | 大きな時計 + 日付。上昇で緑、下落で赤になる BTC 価格ティッカー付き。12 / 24 時間形式を選択可能、日付形式も設定可能。 |
| 5     | **Price**  | 2 つのモード：<br/>• **K-line** — メイン通貨のローソク足チャート、設定可能な間隔（`15m`, `1h`, `4h`, `1d`, …）。<br/>• **Wall** — 複数通貨ウォッチリスト表示（最大 20 ペア）。 |
| 6     | **Weather**| 現在の天候 + AQI + 3 日間予報 + 日の出 / 日の入り。温度（°C / °F）、風速（km/h / mph / m/s）、高度計（気圧 / 湿度）の単位を選択可能。 |
| 7     | **Ladder** | **オプトイン** のグローバル Top-10 リーダーボード。過去最高シェア難易度でランク付け。ウォレットはプライバシーのため `先頭4…末尾4` で表示。デフォルトはオフ。同じデータは [ladder.nmminer.com](https://ladder.nmminer.com/) でも公開されます — [Ladder](./ladder.md) を参照。 |

:::info
ページの順序はすべてのボードで同じです。小型 / OLED 画面は収まらないページをスキップします。NMMiner はあなたがいたページを記憶し、電源サイクル後にそこから再開します（v1.8.20 以降）。
:::

## スクリーンセーバー

マイナーを十分に長く放置すると、スクリーンセーバーに入ります：

- **画像モード** — NM Monitor 経由でアップロードしたカスタム画像のスライドショー。
- **ブラックモード** — バックライトをオフ（または OLED コントラストを最小）にして、最小の消費電力と **絶対的なピークハッシュレート** を実現します。

ウェイクジェスチャー：`BOOT`（または `USER`）のシングルクリック、またはタッチスクリーンをタップ。詳細: [スクリーンセーバー](./screen-saver.md)。
